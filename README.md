# Spotify Playlist Player

A minimal, full-screen page that embeds a Spotify playlist.

## Live page

https://dlxscloude.github.io/spotify-playlist/

## Playlist

The page embeds the Spotify playlist with ID `0XWPTtClSw8qKBRDHX70ZX`. The player is provided by Spotify and requires an internet connection. Playback and availability are subject to Spotify's service, account, and regional requirements.

## Project files

- `index.html` — the standalone page and Spotify embed.
- `.github/workflows/pages.yml` — publishes the site to GitHub Pages when changes are pushed to `main`, or when manually triggered.

## Run locally

Open `index.html` in a browser. The embedded Spotify player needs an internet connection.

## Deployment

Push changes to the `main` branch. The GitHub Actions workflow deploys the repository root to GitHub Pages.
